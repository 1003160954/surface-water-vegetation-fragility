# Reproducibility and scope

The repository separates historical algorithm reproduction from physically corrected1km context analysis. Historical cell59 risks, AFB point estimates and intervals reproduce to recorded tolerances. Corrected classification/model outputs and new crop-exclusion evidence are separate. A later source recovery supersedes the initial E00 manifest's notebook-not-found status; the earlier manifest remains a dated run record.

All quantitative figures are deterministic plots of recorded numerical outputs. AI assistance was used in coding, auditing and drafting during the revision; an original recovered code note also references ChatGPT. Numerical reproducibility cannot prove whether prose used AI, and AI disclosure cannot substitute for numerical verification. The original illustrative infographic's production history is not established; current diagrams do not use image generation.

Public scope is code, source metadata, derived evidence and visualizations. Manuscript/rebuttal Word drafts, text embedded in their authoring generators, private paths/credentials and the old localGit history are excluded. The new public history begins from this filtered tree. No heavy cloud task was resumed for these local additions.
